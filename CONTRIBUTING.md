# Panduan Kontribusi

1. Pilih atau ajukan pekerjaan melalui **GitHub Issues**; sebutkan tim dan penanggung jawab.
2. Buat cabang, misalnya `t01/ST-02-perbaikan-tutor`.
3. Gunakan berkas di `templat/` untuk menambah prompt, skill, kasus, pengetahuan, atau alur kerja.
4. Isi metadata, sertakan sumber, contoh, pengujian, batasan, serta identitas kontributor yang disepakati.
5. Ajukan pull request dan minta **reviewer dari tim berbeda**.
6. Perbaiki hasil sebelum pengelola menggabungkan perubahan ke `main`.

## Etika

Gunakan Bahasa Indonesia, saling menghargai, dan arahkan kritik kepada karya. Jangan mengunggah data pribadi, kunci API, soal ujian rahasia, maupun karya berhak cipta tanpa izin.

## Status paket

`draft` → `in_review` → `beta` → `verified` atau `deprecated`.

Status `verified` hanya berarti lolos pengujian yang tercatat, bukan jaminan selalu benar.

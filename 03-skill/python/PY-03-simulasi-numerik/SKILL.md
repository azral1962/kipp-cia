# PY-03 — Skill Simulasi Numerik Python

## Tujuan

Membantu mahasiswa mengubah model matematis menjadi program Python, menjalankan eksperimen, membandingkan hasil dengan acuan, dan menjelaskan keterbatasan simulasi.

## Masukan

Definisi masalah, parameter, asumsi model, hasil yang diharapkan dan metode pembanding.

## Prosedur

1. Pastikan persoalan dan satuan setiap parameter jelas.
2. Rumuskan model, asumsi, dan algoritma.
3. Buat program Python yang dapat dijalankan ulang.
4. Jalankan simulasi dan simpan hasil.
5. Bandingkan dengan perhitungan analitik atau acuan yang dapat diperiksa.
6. Buat tabel atau grafik bila diperlukan.
7. Catat kesalahan, ketidakpastian, dan interpretasi.

## Keluaran

Program `.py`, data hasil, grafik atau tabel, serta penjelasan.

## Kriteria penerimaan

Program berjalan, parameter terdokumentasi, hasil dapat direproduksi, dan pemeriksaan numerik dinyatakan secara eksplisit.

# Kebutuhan MVP

## Fungsional

- KR-01: katalog menampilkan prompt dan skill dari metadata YAML dengan penjelasan Bahasa Indonesia.
- KR-02: pengguna dapat mencari judul, kode, dan kategori.
- KR-03: entri menampilkan petunjuk lengkap, versi, dan status review.
- KR-04: kontribusi dilakukan melalui template dan pull request dengan ulasan silang.
- KR-05: contoh memuat penerapan dari mata kuliah berbeda.
- KR-06: minimal satu alur kerja menunjukkan belajar → riset → desain → implementasi → paper → komunikasi.
- KR-07: bot Telegram tahap awal melayani `/help` dan `/find` pada grup dan supergrup yang menambahkannya.

## Nonfungsional

- Seluruh teks untuk mahasiswa berbahasa Indonesia.
- Aplikasi katalog berjalan lokal tanpa model AI ataupun database eksternal.
- Tidak membutuhkan akun AI berbayar.
- Rahasia tidak disimpan dalam kode; privasi dan hak cipta dijaga.
- Hasil dapat diekspor serta dipelihara antarsemester.

## Di luar lingkup MVP

Pemantauan percakapan Telegram penuh, pemberian saran berbasis LLM, penyimpanan percakapan, aplikasi mobile, dan sistem produksi multi-agent. Semua ini memerlukan desain keamanan dan persetujuan tambahan.
